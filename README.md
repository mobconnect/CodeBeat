# CodeBeat\n\nCodeBeat is a powerful code quality analysis tool designed to help developers improve code quality through AI-powered metrics and feedback.\n\n## 🚀 Features\n\n- **Code Quality Analysis**: Analyze code for quality metrics\n- **AI-Powered Feedback**: Get intelligent suggestions using Gemini API\n- **Multi-language Support**: Support for multiple programming languages\n- **Beautiful Dashboard**: Intuitive interface for viewing results\n- **Real-time Analysis**: Instant feedback on your code\n\n## 📋 Prerequisites\n\n- Node.js >= 18.0.0\n- npm >= 9.0.0\n- Gemini API Key\n\n## 🔧 Installation\n\n```bash\ngit clone https://github.com/mobconnect/CodeBeat.git\ncd CodeBeat\nnpm install\n```\n\n## 🏃 Running Locally\n\n```bash\n# Development server\nnpm run dev\n\n# Production build\nnpm run build\n\n# Preview build\nnpm run preview\n```\n\nVisit `http://localhost:3000` to access the application.\n\n## 📝 Available Scripts\n\n- `npm run dev` - Start development server\n- `npm run build` - Build for production\n- `npm run preview` - Preview production build\n- `npm run clean` - Clean build artifacts\n- `npm run lint` - Lint code\n\n## 🎨 Technology Stack\n\n- React 19\n- TypeScript\n- Vite\n- Tailwind CSS\n- Gemini API\n- Express.js\n\n## 📄 License\n\nMIT License - See LICENSE file for details\n
